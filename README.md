# 🤖 TEK-BOT (Android App)

Cette application mobile est un **chatbot Android en Java** pour l’Université Privée TEK-UP.  
Il répond automatiquement aux questions fréquentes sur :

- 📍 Localisation de TEK-UP  
- 📝 Conditions d’admission  
- 🎓 Formations disponibles  
- 🎉 Vie étudiante  
- 👋 Salutations (bonjour / au revoir)

## 🚀 Fonctionnalités
- Réponses automatiques basées sur des mots-clés  
- Interface simple type "messagerie"  
- Gestion des salutations et au revoir  
- Informations de contact TEK-UP intégrées  

---
👩‍💻 Développé avec ❤️ en Java / Android Studio
